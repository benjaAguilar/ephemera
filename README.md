# Ephemera

Ephemera is an open-source anonymous messaging application focused on privacy, temporary communication, and learning modern backend technologies

Unlike traditional messaging platforms, Ephemera does not require personal information to create an account. Users and conversations are designed to exist only for a limited amount of time defined by the creator. Once that lifetime expires, all related data is permanently deleted

The goal is simple:

> Your conversations should disappear when you decide—not live forever on someone elses servers

Conversations in Ephemera do not outlive their creator

Every room, every group, and every message exists only while its creator exists. Once the creator's identity expires, everything created by that identity disappears as well

No abandoned groups
No forgotten messages
No permanent digital footprints

> Nothing in Ephemera is meant to outlive its purpose

---

## Philosophy

Modern messaging applications often encourage users to create permanent digital identities and store conversations indefinitely.

Ephemera explores a different approach.

- Anonymous identities
- Temporary conversations
- End-to-end encryption
- Automatic data deletion
- Privacy by default

---

## Why this project?

Ephemera is primarily a learning project.

The objective is to build a production-like application while exploring technologies and architectural patterns commonly used in real-world software engineering, including:

- Monorepos (pnpm workspaces)
- Docker
- CI/CD pipelines
- WebSockets
- End-to-end encryption (Web Crypto API)
- Scheduled jobs
- Modern frontend architecture
- Scalable backend design
- Automated testing

Rather than building a minimal demo, the goal is to understand how these technologies work together in a complete application.

## Contributing

Contributions are welcome.

Since Ephemera is intended as a learning project, contributors are expected to understand and explain the code they submit.

To encourage genuine learning, pull requests or issues that appear to be generated primarily by AI coding agents may be rejected. Using AI as a reference or learning tool is acceptable, but contributions should reflect your own understanding of the implementation.

If you're interested in privacy, distributed systems, or simply learning by building, feel free to join the project.
